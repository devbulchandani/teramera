# teramera-product

Product design system for **teramera** — an expense-splitting app for friends (India-first, INR primary).

## Brand understanding

"teramera" = *tere + mera* (yours + mine). The identity leans into this duality: two matched accents (teal = mera/yours-side actions, violet = tere/their-side identity), mirrored layouts, split motifs. Warm and clean rather than dark-fintech-serious — money between friends should feel friendly.

- Market: India-first, bold energy, but restrained execution
- Personality: clean & warm; generous whitespace; big expressive numerals for money
- Currency: INR default (₹), multi-currency aware

## Sources consulted

- User design brief (this session): market feel, personality, accents, novelty level
- No existing brand assets or Figma; Android codebase is a fresh Compose template
