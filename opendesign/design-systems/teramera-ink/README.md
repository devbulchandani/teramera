# teramera-ink

Second-generation design system for teramera, derived from the supplied
reference: ink canvas, cream paper, peach light, heavy rounding, mascot-led.

- `tokens/colors_and_type.css` — all tokens, light + dark.
- `brand/style-notes.md` — surfaces, shape, type, mascot placement, motion.
- `SKILL.md` — portable agent instructions.

Supersedes `teramera-product`. Prototypes live in
`opendesign/mockups/ink-system/`.
